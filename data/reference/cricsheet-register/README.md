# Cricsheet Register

These snapshots of `people.csv` and `names.csv` come from the official
[Cricsheet Register](https://cricsheet.org/register/). They map the player-name
variants used in the historical match data to stable third-party identifiers.

Downloaded: 2026-09-08

The register is provided under the
[Open Data Commons Attribution License](https://opendatacommons.org/licenses/by/1-0/).
This project contains information from the Cricsheet Register, maintained by
Cricsheet (cricsheet.org).

The CSV files contain identity metadata only. Player images are loaded lazily
from ESPN's public image CDN using the corresponding ESPNcricinfo identifier and
are not copied into this repository.
